10 проектов: AI-платформы, финтех, продукты для здоровья и образования. У приватных репозиториев ссылка открывается только при доступе — это помечено на карточке.

  1. 01

    Образование · игра

    История Казахстана — «аквариум рисунков»

    Ребёнок раскрашивает распечатанный контур исторического персонажа, фотографирует лист телефоном — и персонаж оживает на большом экране, а рассказчик излагает его историю по школьному учебнику.

    • Node.js
    • TypeScript
    • Fastify
    • React
    • WebSocket
    • —Монорепозиторий из четырёх частей: сервер, экран-аквариум, мобильный сканер, админка учителя
    • —Сервер выравнивает фотографию по угловым маркерам листа и вырезает рисунок в текстуру
    • —100 двуязычных карточек дат ЕНТ; факт без ссылки на страницу учебника в игру не попадает — это проверяет валидатор контента
    • —Работает офлайн в школьной сети: фотографии обрабатываются локально, имя ребёнка живёт только в рамках урока

    AI-платформа · маркетинг

    Marketing Stack OS

    Мультитенантная платформа автоматизации маркетинга. Один источник правды о бренде — Brand Brain, — из которого генерируются смыслы, офферы и контент.

    • FastAPI
    • PostgreSQL
    • pgvector
    • Celery
    • Anthropic API
    • —Brand Brain на RAG: источник → чанкинг → эмбеддинги → поиск контекста; на Postgres — нативный pgvector
    • —Agent Runtime по схеме generate → critique → refine с учётом токенов и бюджета тенанта
    • —Жёсткая изоляция данных по tenant_id: чужое отдаётся как 403, без утечки самого факта существования
    • —Ничего не публикуется само — всё сгенерированное уходит в статус review

  3. 03

    Финтех · налоги

    НалогоКонтроль

    Платформа налогового риск-контроля для агросектора Казахстана. Находит расхождения по ЭСФ, невычитаемые расходы и отсутствующую первичку раньше, чем их найдёт налоговая, и выдаёт отчёт с суммой риска в тенге.

    • FastAPI
    • Next.js
    • Supabase
    • Postgres + RLS
    • —Вся обработка локальная — данные не покидают периметр клиента, облачных API нет
    • —Монорепозиторий: Engine API, веб-приложение и benchmark-harness для оценки локальных VLM на казахстанской первичке
    • —Confident-gate на распознавании: проверка контрольной суммы БИН и арифметики документа
    • —Методологические допущения вынесены в конфиг и помечены как ждущие подтверждения эксперта

  4. 04

    Здоровье · сенсинг

    Пансион — пост дежурной

    Мониторинг дома престарелых на бесконтактном WiFi-сенсинге ESP32 + CSI, без камер. Одна страница со всеми палатами и тревогами, отсортированными по срочности.

    • Python
    • FastAPI
    • MQTT
    • WebSocket
    • ESP32 / CSI
    • —Персоналу показываются только производные состояния благополучия — сон, активность, дистресс, риск падения; сырые дыхание и пульс на пост не выводятся
    • —Движок правил ухода: выход из кровати — низкий приоритет днём у самостоятельного, критический для лежачего
    • —Эскалация неподтверждённых тревог по таймеру: смена → старшая медсестра → родственник
    • —Ядро правил чистое — без сети и состояния, тестируется на голом Python

    Хакатон · HackAlem AI

    Versa — сравнение организационных документов

    Прототип для задачи Казахтелекома: сравнение редакций положений и регламентов с подготовкой сравнительной таблицы и заключения. В одной строке — исходная формулировка, новая и пояснение к изменению.

    • Python
    • Pyodide
    • difflib
    • DOCX / XLSX / PDF
    • —Постатейное сравнение с сохранением контекста пунктов и разбором перенумерации
    • —Проверка функций и полномочий: пересечения, смена владельца функции, противоречия — каждое замечание связано с исходным фрагментом
    • —Импорт DOCX, PDF, XLSX, MD, CSV; выгрузка в DOCX, XLSX, PDF, HTML, CSV и JSON
    • —Браузерная сборка на Pyodide — тот же Python-движок без установки

  7. 07

    AI-компаньон · здоровье

    Алина — голосовой компаньон для пожилых

    Напоминает о лекарствах, замечает падения, разговаривает по-русски и по-казахски и сообщает близким, когда что-то идёт не так.

    • Node.js
    • Fastify
    • PostgreSQL
    • Python
    • Wear OS
    • —Решение позвать помощь не зависит от модели: тревожные фразы разбираются локальными правилами — сеть может лежать, а помощь звать всё равно нужно
    • —Вызов скорой закрыт тремя предохранителями и по умолчанию выключен; короткие номера экстренных служб заблокированы отдельно
    • —Внешние сервисы опциональны: нет ключа — заготовка, нет Telegram — очередь с объяснением, нет голосового сервиса — текстовый режим
    • —158 тестов бэкенда и 16 голосового сервиса, все офлайн — в сеть не ходят и денег не тратят

  8. 08

    ERP · дома престарелых

    Alina — ERP для пансионатов

    Цифровой учёт вместо бумаги: свой контекст у каждой роли — владелец сети, директор пансионата, медсестра. Фиксация выдачи лекарств с обязательным подтверждением и сверкой с назначением.

    • Python
    • FastAPI
    • React
    • PostgreSQL
    • IndexedDB
    • —Журнал выдачи неизменяем: нет PATCH и DELETE, исправление — только новой записью со ссылкой на исправляемую
    • —Голосовая фиксация через Claude со строгой JSON-схемой: непонятые поля обязаны быть null, «додумывание» запрещено схемой
    • —Офлайн для медсестёр: очередь в IndexedDB и service worker — записи уходят сами, когда связь вернётся
    • —Чужой и несуществующий ID дают одинаковый 403 — различие раскрывало бы факт существования записи

  9. 09

    Финтех · бухгалтерия

    Налоговая платформа РК

    Два модуля для бухгалтера: вычеты по КПН и сверка ЭСФ между 1С и ИС «ЭСФ». Загружаете выгрузки — получаете готовые Excel-отчёты, данные обрабатываются локально.

    • Python
    • FastAPI
    • pandas
    • openpyxl
    • Render
    • —Автообработка по папке: платформа определяет файлы по их колонкам, имена не важны, и собирает комплекты сама
    • —Файл берётся в работу, только если «отлежался» три секунды — чтобы не схватить ещё не дописанную выгрузку
    • —Соответствие колонок вынесено в словари: под чужие выгрузки правится маппинг, логика расчётов не меняется

    Сайт · сдан заказчику

    Портфолио методиста дошкольного образования

    Одностраничный сайт-портфолио с архивом из тридцати документов по семи разделам и автономным ассистентом. Собран и выложен под ключ, работает по публичному адресу.

    • Next.js
    • TypeScript
    • Tailwind
    • Framer Motion
    • —Статический экспорт: ассистент отвечает по базе знаний в самом бандле — без сервера, API-ключа и интернета
